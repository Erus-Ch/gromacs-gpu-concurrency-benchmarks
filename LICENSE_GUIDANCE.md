# Reuse and attribution

Before a formal public release, the owner should choose a license for the original scripts and a license for the original report/data. Common choices are MIT for original code and CC BY 4.0 for original report/data. This guidance file itself does not grant those licenses or change third-party terms.

Add the selected license texts and public attribution name before the final release. Scope them explicitly: upstream GROMACS input material, NVIDIA header excerpts in the compatibility patch, and third-party dependencies retain their applicable terms. The binary input and dependencies are not bundled.
